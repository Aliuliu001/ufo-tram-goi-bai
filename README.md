# 🛸 UFO Trạm Gọi Bài

Game gọi học sinh ngẫu nhiên dùng trong lớp học, chạy trực tiếp trên web.

## Mở game
Sau khi GitHub Pages hoàn tất, mở: <https://aliuliu001.github.io/ufo-tram-goi-bai/>

Nếu vừa có bản mới mà anh vẫn nhìn thấy giao diện cũ: bấm **Ctrl + Shift + R**.

## Cách dùng bản hiện tại
1. Bấm **⚙️ Chỉnh danh sách**.
2. Xóa danh sách mẫu và dán tên học sinh — mỗi dòng một tên.
3. Bấm **💾 Lưu danh sách**.
4. Bấm **🎨 Đổi skin** nếu muốn thay trang phục/màu cho UFO.
5. Bấm **🎲 Gọi học sinh**. Mỗi bạn chỉ được gọi một lần trong lượt.
6. Bấm **↻ Làm lại lượt** để gọi lại từ đầu.

## Dữ liệu
- Danh sách hiện được lưu trong trình duyệt đang mở game.
- Không có tên học sinh thật trong mã nguồn GitHub.
- Bản sau sẽ thêm câu hỏi, chấm Đúng/Sai và nút sao lưu/khôi phục.

## Phát triển
- `npm test`: kiểm tra luật gọi không trùng.
- `npm run check`: kiểm tra cú pháp JavaScript.
